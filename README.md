# Бот проверки статуса домашней работы (VK)

Бот для Практикума: уведомления о статусе домашней работы приходят в VK.

Раз в 10 минут бот запрашивает API Практикум.Домашка, проверяет ответ и при смене статуса отправляет сообщение в VK.

## Что нужно для запуска

- Python 3.10+
- токен API Практикум.Домашка
- ключ сообщества VK с правом отправки сообщений
- числовой `id` пользователя VK, которому писать

## Установка

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

Создайте файл `.env` в корне проекта (он уже в `.gitignore`):

```
PRACTICUM_TOKEN=<токен Практикума>
VK_TOKEN=<ключ сообщества VK>
VK_USER_ID=<id пользователя VK>
```

Имена переменных менять нельзя: их ждут автотесты.

## Запуск

```bash
python homework.py
```

При отсутствии любой обязательной переменной окружения бот пишет запись уровня `CRITICAL` и завершает работу.

## Как устроен код

| Функция | Задача |
| --- | --- |
| `check_tokens()` | проверяет `PRACTICUM_TOKEN`, `VK_TOKEN`, `VK_USER_ID` |
| `get_api_answer()` | GET на `https://practicum.yandex.ru/api/user_api/homework_statuses/` |
| `check_response()` | проверяет, что в ответе есть `homeworks` и `current_date` |
| `parse_status()` | собирает текст уведомления по статусу |
| `send_message()` | отправляет сообщение в VK |
| `main()` | запускает цикл опроса раз в 10 минут |

Запрос к API идёт с заголовком `Authorization: OAuth <token>` и параметром `from_date` (Unix time).

Однотипные ошибки в VK не дублируются: повтор уходит только в лог.
